Concepts Clés

Partie 1 - Découvrez le web et ses origines

Web

Le Web (World Wide Web) est un système qui permet de consulter et de partager des informations sur Internet grâce à des pages web, des images, des vidéos et des liens hypertextes. Il a été inventé par Tim Berners-Lee en 1989.

Internet

Internet est un réseau mondial qui relie des millions d'ordinateurs, de téléphones et d'autres appareils afin de permettre l'échange de données et la communication entre eux.

Cloud

Le Cloud (ou informatique en nuage) permet de stocker, consulter et utiliser des données ou des services à distance grâce à Internet, sans avoir besoin de tout conserver sur son propre appareil.

W3C

Le W3C (World Wide Web Consortium) est une organisation internationale créée par Tim Berners-Lee qui développe et définit des standards et des règles techniques pour le Web, afin de garantir son bon fonctionnement et son accessibilité.

Partie 2 - Distinguez les langages du Web

Langages client

Les langages client sont des langages de programmation utilisés pour créer et afficher le contenu et l'interactivité d'une page Web directement dans le navigateur de l'utilisateur. Les principaux sont HTML, CSS et JavaScript.

Navigateurs

Un navigateur Web est un logiciel qui permet de consulter des sites et des pages Web sur Internet. Il interprète notamment les langages comme HTML, CSS et JavaScript pour afficher les pages à l'écran.

Langages serveur

Les langages serveur sont des langages de programmation utilisés pour exécuter des actions sur un serveur, comme traiter des données, gérer des comptes ou communiquer avec une base de données, avant d'envoyer le résultat au navigateur. Parmi eux, on trouve PHP, Python, Java et JavaScript (Node.js).

Frameworks

Les frameworks sont des ensembles d'outils, de bibliothèques et de règles qui permettent aux développeurs de créer des applications et des sites Web plus rapidement et plus facilement. Parmi eux, on trouve React, Angular, Vue.js et Laravel.

Bases de données

Une base de données est un système qui permet de stocker, organiser et gérer des informations afin de pouvoir les consulter, les modifier ou les supprimer facilement. Les données peuvent être gérées avec des systèmes comme MySQL, PostgreSQL ou SQLite.

Site responsive

Un site responsive est un site Web dont l'affichage s'adapte automatiquement à la taille et à la résolution de l'écran utilisé, que ce soit sur un ordinateur, une tablette ou un smartphone.

Application mobile

Une application mobile est un logiciel conçu pour être utilisé sur un smartphone ou une tablette. Elle permet d'effectuer différentes tâches, comme communiquer, jouer, consulter des informations ou utiliser des services.

Partie 3 - Découvrez le fonctionnement du réseau

Serveurs

Un serveur est un ordinateur ou un système informatique qui stocke, traite et fournit des données ou des services à d'autres appareils connectés à un réseau, comme Internet. Il peut par exemple héberger des sites Web, des applications ou des bases de données.

Adresse IP

Une adresse IP (Internet Protocol) est un numéro unique attribué à un appareil connecté à un réseau, qui permet de l'identifier et de communiquer avec d'autres appareils sur ce réseau.

Nom d'hôte et DNS

Un nom d'hôte (hostname) est un nom qui permet d'identifier un appareil ou un serveur sur un réseau. Le DNS (Domain Name System) est un système qui traduit les noms de domaine ou noms d'hôte en adresses IP, afin que les appareils puissent communiquer entre eux.

Protocoles

Les protocoles sont des règles de communication qui permettent aux appareils connectés à un réseau de communiquer et d'échanger des données correctement. Parmi les principaux protocoles, on trouve HTTP, HTTPS, TCP/IP, FTP et DNS.

Partie 4 - Identifiez les métiers du web

Développeurs

Les développeurs sont des professionnels de l'informatique qui conçoivent, programment, testent et maintiennent des logiciels, des sites Web ou des applications à l'aide de langages de programmation.

Product Managers et chefs de projets

Un Product Manager est une personne qui définit les besoins et les objectifs d'un produit, notamment en fonction des attentes des utilisateurs, et coordonne son évolution. Un chef de projet est une personne qui organise et coordonne la réalisation d'un projet, en veillant au respect des délais, du budget et des objectifs.

Designers

Les designers sont des professionnels qui conçoivent l'apparence, l'ergonomie et l'expérience utilisateur d'un site Web, d'une application ou d'un produit, afin de le rendre clair, esthétique et facile à utiliser.

Testeurs

Les testeurs sont des professionnels qui vérifient le bon fonctionnement d'un logiciel, d'un site Web ou d'une application en recherchant des erreurs, des bugs et des problèmes d'utilisation, afin d'améliorer sa qualité et sa fiabilité.

Techniciens informatique

Les techniciens informatiques sont des professionnels qui installent, configurent, entretiennent et dépannent les ordinateurs, les réseaux et les équipements informatiques. Ils peuvent également aider les utilisateurs à résoudre leurs problèmes techniques.

Langages de développement web

HTML

Front-End

Le HTML (HyperText Markup Language) est un langage de balisage utilisé pour structurer le contenu d'une page Web, comme les textes, les images, les liens, les tableaux et les formulaires.

CSS

Front-End

Le CSS (Cascading Style Sheets) est un langage utilisé pour mettre en forme et styliser une page Web, notamment les couleurs, les polices, les tailles, les espacements et la disposition des éléments.

JavaScript

Front-End

Le JavaScript est un langage de programmation principalement utilisé pour rendre les pages Web interactives et dynamiques, par exemple en ajoutant des animations, des boutons interactifs ou en modifiant le contenu d'une page.

JavaScript

Back-End

Le JavaScript est un langage de programmation qui permet d'ajouter du comportement et de l'interactivité aux pages Web, par exemple en réagissant aux clics, aux actions de l'utilisateur ou aux événements sur une page.

PHP

Back-End

Le PHP (Hypertext Preprocessor) est un langage de programmation côté serveur principalement utilisé pour créer des pages Web dynamiques, traiter des données et communiquer avec des bases de données.

Java

Back-End

Java est un langage de programmation polyvalent utilisé pour créer des applications, des logiciels, des applications mobiles et des services côté serveur. Il est conçu pour pouvoir fonctionner sur différents systèmes grâce à la machine virtuelle Java (JVM).

Python

Back-End

Python est un langage de programmation simple et polyvalent, utilisé notamment pour créer des applications, des logiciels, des sites Web, automatiser des tâches et développer des systèmes d'intelligence artificielle.

C#

Back-End

C# (C-Sharp) est un langage de programmation développé par Microsoft, utilisé notamment pour créer des logiciels, des applications, des jeux vidéo avec Unity et des applications Web.

SQL

Bases de données

Le SQL (Structured Query Language) est un langage utilisé pour créer, consulter, modifier et supprimer des données dans une base de données. Il est notamment utilisé avec des systèmes comme MySQL, PostgreSQL et SQLite.
